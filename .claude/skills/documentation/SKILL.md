# Documentation Update Checklist

After completing any task, update relevant documentation:

## Always Update
- `docs/PROJECT.md` - Add session notes describing what was done

## Update If Changed
- `docs/API.md` - New/modified API endpoints
- `docs/ARCHITECTURE.md` - Infrastructure or design changes
- `README.md` - New features or setup changes
- `CONTRIBUTING.md` - Development workflow changes
- `frontend/README.md` - Frontend feature changes
- `backend-ts/README.md` - Backend function changes

## Session Notes Format
Add to docs/PROJECT.md:
```markdown
### Session: YYYY-MM-DD - Brief Title
- What was implemented
- Key decisions made
- Any known issues or follow-ups
```
